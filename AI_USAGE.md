- UNIQUE COLLATE NOCASE: enables to compare ingredients taking away case sensitivity
- ON DELETE CASCADE: when a recipe is deleted, it deletes all of the ingredients in recipe_ingredients that have been related to the respective recipe. This makes it so that an ingredient doesn't exist for a recipe that does not exist anymore
- ON DELETE RESTRICT: when an ingredient exists in recipe_ingredients, the user cannot delete it because it has already been implemented. Therefore, the recipe won't be left out without the ingredient it requires.
- unit IN ('g', 'kg', 'ml', 'l', 'tsp', 'tbsp', 'pcs'): this ensures that the unit that is being added is accepted by sqlite3. This makes it easier for conversions because these metrics come from the same unit family (g to kg).
