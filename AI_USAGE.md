| 2026-09-28/c1c8247         | Claude | Review the sql schema I wrote explain unit_list, COLLATE NOCASE, ON DELETE CASCADE | Modified                                 | I wrote the schema, fixed int vs INTEGER PRIMARY KEY, IF NOT EXISTS, FK syntax, added RESTRICT                                      | In recipes.id it is INTEGER PRIMARY KEY so that every time a recipe is added the id also increments and each recipe has its own distinct id progressively.
